### 🚀 Featured Projects

#### 🥇 Flagship Project — RAG-Based University Academic Advising Assistant

**Graduate Research Project | California State University, Dominguez Hills**

An AI-powered academic advising assistant that helps students get accurate answers about degree requirements, courses, and university policies, using Retrieval-Augmented Generation (RAG) over the university's own catalogs and documents.

**Tech Stack:** Python, FastAPI, LangChain, FAISS, LLMs, RAG

**Key Highlights:**
- Built a document pipeline that splits university PDFs into searchable sections with vector embeddings.
- Built FastAPI endpoints for natural-language questions, semantic retrieval, and source attribution.
- Developed a chat-style interface that shows every answer with its sources, so students can check it.
- Built an evaluation comparing a plain LLM with the RAG pipeline on accuracy, relevance, hallucinations, and citations.

**Status:** Final development and documentation in progress. *Source code is currently private; a demo is available on request.*
